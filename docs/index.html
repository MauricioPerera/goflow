Position

n8n and Zapier were built for a person to click through.
goflow was built for an agent to operate.

Most automation platforms added an AI node to an existing canvas. That gets you a chatbot that can configure the canvas for you — it still ends at a UI a human has to open, inspect, and click "activate" in.

goflow has no canvas. A flow is JSON. A piece is JSON with a JavaScript function inside it. Both are created, versioned, run, and rolled back through the same MCP tool surface a human would use over HTTP — which means an agent doesn't need permission to act differently than a person; it already has the identical surface a person has.

That's the actual bet: not "AI-assisted automation," but automation where the agent is the primary operator, and the API was designed for that from the first line of code, not retrofitted onto a drag-and-drop tool built for a different audience.

How it actually works

An agent builds and runs a flow in one exchange

No screen to open, no node to drag. This is the entire round trip — describe the catalog, save a piece, run it.

01 — Discover

goflow_describe_catalog

The agent asks what's available — every built-in piece and every JS-authored one, with real input schemas — before it writes a single line.

02 — Author

goflow_save_piece

A new integration is a name, a JS function, and at least one worked example. goflow actually runs every example before it accepts the piece — no example, no save.

03 — Run

goflow_save_flow · goflow_run_flow

The flow is saved, validated against the live registry, and executed — recorded in history, replayable later against whatever the flow looks like by then.

Guarantees, not vibes

Every save is verified. Every edit is reversible.

// examples run for real

Nothing is saved untested

A piece's worked examples aren't schema hints — goflow executes each one before persisting. A broken piece never reaches the catalog.

// nothing is ever overwritten

Full history, one rollback away

Every save of a flow — or a single piece — records an immutable version. Roll back through the same gate a live edit goes through, no exceptions.

// prove it before you trust it

Replay real traffic against an edit

Take any past run and re-fire its exact trigger against the flow's current definition — see whether your change actually altered behavior, before anyone else finds out.
